如果学生端找不到

现象排查
一直显示"正在寻找考试主机" 1. 确认本页显示"广播已开启"
2. 服务器防火墙放行 UDP {{ stats.beacon_port or 39100 }}：
ufw allow 39100/udp 或 firewall-cmd --add-port=39100/udp
3. 学生机和服务器是否在同一网段
提示"收到广播但连接失败" 广播听到了，但 HTTP 端口不通。检查防火墙放行了 TCP {{ port }}：
ufw allow {{ port }}/tcp
跨网段 / 走了三层交换机 广播不跨网段。改用组播启动：
python3 app.py --multicast
（需要交换机开 IGMP Snooping）
就想手动指定 学生端 config.json 里填 "server": "http://192.168.1.5:{{ port }}"， 或用 考试客户端.exe --server http://...
